| 程式名稱 | 功能 | 使用時機 |
|---------|------|---------|
| `run_bom_pipelineV2.py` | 主程式：BOM 正規化處理 | 處理 BOM Excel 檔案 |

## 🚀 完整使用流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                         一般使用流程                                  │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  1️⃣ 準備 BOM Excel 檔案                                             │
│       ↓                                                             │
│  2️⃣ 執行 run_bom_pipelineV2.py                                      │
│       ↓                                                             │
│  3️⃣ 檢視輸出的 _AUTO.xlsx 和 _REVIEW.xlsx                           │
│       ↓                                                             │
│  4️⃣ 人工審核 _REVIEW.xlsx 並修正                                    │
│       ↓                                                             │
│  ✅ 完成！使用正規化後的資料                                          │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────┐
│                       AI 模型訓練流程（進階）                         │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  1️⃣ 完成上述一般使用流程                                             │
│       ↓                                                             │
│  2️⃣ 人工審核 _REVIEW.xlsx 並修正所有欄位                            │
│       ↓                                                             │
│  3️⃣ 執行 convert_to_training_data.py 轉換為訓練格式                 │
│       ↓                                                             │
│  4️⃣ 使用新訓練資料重新訓練 NER 模型                                  │
│       ↓                                                             │
│  5️⃣ 將新模型放入 distilbert_ner_final 資料夾                        │
│       ↓                                                             │
│  ✅ 完成！下次執行將使用更準確的 AI 模型                               │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```
